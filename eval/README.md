# Evaluation set

`questions.jsonl` is generated by `python -m eval.make_questions` from:

| id prefix | source | verified? |
|---|---|---|
| `d..` | **drafted** by the AI assistant from the lecture transcripts | **No: you must check them** |
| `h..` | **human** pilot queries from `data/annotations/gold/*.json` | yes |
| `o..` | **out-of-scope** questions that must be refused | the script checks their key terms never appear in the index |

Each in-scope question stores its gold answer as a time span (`video_id`, `start`, `end` in seconds). `eval/gold.py` maps the span to segment IDs of the current index, so gold labels survive re-segmentation.

## How to verify the drafted questions (manual, about 1 hour)

For each `d..` question in `eval/make_questions.py` (`DRAFTED` list, times in mm:ss):
1. Open the video at the start time.
2. Check that the span actually answers the question. Fix `start`/`end` if the explanation begins earlier or ends later; delete the question if the lecture does not really answer it.
3. Re-run `python -m eval.make_questions`, then `python -m eval.run`.

Why it matters: the drafted questions were written by reading transcripts, so they tend to reuse lecture vocabulary. That favours BM25 and inflates every score. The human-written subset is the more honest signal, and it is reported separately.
